What is inspercidados?

A thin, opinionated wrapper around the dataverse package.

Insper Cidades produces clean, curated datasets on Brazilian cities — IPTU records, transit flows, real-estate transactions, and more. These datasets live on Insper's Dataverse instance. inspercidados gives researchers a single, consistent way to discover, load, and cite these datasets without knowing anything about Dataverse's API.

# Install from GitHub (development version)
remotes::install_github("insper-cidades/inspercidados")

# Install from CRAN (once published)
install.packages("inspercidados")

Core Functions

Three functions cover everything a researcher needs.

list_datasets()

Browse all available datasets. Filter by keyword. No internet call — reads the local registry instantly.

get_dataset()

Download a dataset into R. Returns a tibble or sf object ready to use. Accepts alias, DOI, or URL.

cite_dataset()

Generate a properly formatted citation. Supports plain text, BibTeX, and RIS. Metadata fetched live from Dataverse.

get_script()

Open the reproducible R script for a dataset in your editor. Scripts hosted on GitHub, downloaded on demand.

# By alias (easiest)
iptu <- get_dataset("iptu_sp")

# By DOI
iptu <- get_dataset("10.60873/FK2/7IXFPX")

# By DOI URL
iptu <- get_dataset("https://doi.org/10.60873/FK2/7IXFPX")

# Filter to a specific year
iptu_2023 <- get_dataset("iptu_sp", year = 2023)

# Request a specific file by name
iptu_geo <- get_dataset("iptu_sp", filename = "iptu_2023.gpkg")

# Match files with a regex pattern
trips <- get_dataset("pemob", file_pattern = "trips\\.csv$")

Flexible Identifiers

Every function that takes a dataset argument resolves the identifier automatically.

1

Alias

A short, memorable name like "iptu_sp" — looks up the DOI in the local registry (inst/datasets.json). No network call.

2

DOI

A bare DOI like "10.60873/FK2/7IXFPX" — used directly with Dataverse. Works for any Insper dataset even if it has no alias yet.

3

DOI URL

A full URL like "https://doi.org/10.60873/FK2/7IXFPX" — the DOI is extracted and resolved as above.

Architecture

A thin wrapper. Dataverse is the source of truth.

User code
  get_dataset("iptu_sp")
            ↓
  resolve_dataset("iptu_sp")
            ↓  reads inst/datasets.json
  DOI: 10.60873/FK2/7IXFPX
            ↓
  dataverse::dataset_files()  ↔ Insper Dataverse
            ↓  select file by year / filename / pattern
  dataverse::get_dataframe_by_name()
            ↓  auto-detect format: CSV, Parquet, GPKG, XLSX
  tibble / sf object  with doi attribute attached

inst/datasets.json

Local registry mapping aliases to DOIs and script URLs. Updated when new datasets are added. No duplication of Dataverse metadata.

Insper Dataverse

Single source of truth for file listings, metadata, and downloads. The package hits the API at runtime — data is always current.

GitHub (scripts)

R scripts live in the package repository under inst/scripts/. get_script() downloads from the raw GitHub URL on demand.

R Scripts

What are dataset scripts?

Each dataset has a companion R script that shows a researcher how to load, explore, and work with the data. Scripts are hosted on GitHub and downloaded on demand with get_script(). They open directly in your editor — just run them.

# Opens inst/scripts/iptu_sp.R in your editor
get_script("iptu_sp")

What a script typically contains

  • Load the dataset with get_dataset()
  • Print a summary of key variables
  • A few basic exploratory plots
  • Common transformations and joins relevant to the dataset
  • Links to the original data source and academic papers that used the data

Design Principles

Decisions made to keep the package simple and maintainable.

Thin wrapper

The package does not re-implement anything the dataverse package already does. Minimal surface area, minimal maintenance.

No local metadata duplication

Only the alias→DOI mapping is stored locally. Everything else (titles, authors, files) comes from Dataverse at runtime and is always current.

Heavy deps in Suggests

arrow, sf, and readxl are large. They are optional — loaded only when the user needs a non-CSV format, with a friendly install prompt.

cli for all messages

No bare message() or stop(). The cli package gives consistent, coloured, suppressible output that integrates with modern R tooling.

CRAN from day one

All examples run offline or skip gracefully. R CMD check --as-cran passes with zero notes. Proper Authors@R, SPDX license identifier, URL validation.

One server, hardcoded

The Insper Dataverse server is always dataverse.datascience.insper.edu.br. Users never configure it — fewer moving parts, less confusion.
